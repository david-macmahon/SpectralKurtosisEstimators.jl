# Getting Started

This page walks through a few common tasks you can perform with
SpectralKurtosisEstimators.jl.  The examples below assume that you have already
installed the package as described in the [Home](index.md) page.  To use it,
load it with:

```julia
using SpectralKurtosisEstimators
```

## Creating an SKEstimator

The `SKEstimator` constructor takes three parameters: `M`, `N`, and `d`.  They
may be passed as all positional arguments or all keyword arguments (no mixing
allowed).  These are equivalent:

```julia
ske = SKEstimator(1024, 1, 2)        # All positional arguments
ske = SKEstimator(M=1024, N=1, d=2)  # All keyword arguments
```

where:

- `M`: number of outer sum addends
- `N`: number of inner sum addends
- `d`: half the number of squared voltages summed together per input sample
  (aka the *shape* parameter)

The first four statistical moments of the corresponding generalized spectral
kurtosis estimator are precomputed and stored in the `u1`, `u2`, `u3`, and `u4`
fields.

## Computing spectral kurtosis estimates

The [`skhat`](@ref) function computes spectral kurtosis estimates from data.

### From precomputed `S1` and `S2` values

The spectral kurtosis estimate can be computed from precomputed `S1` and `S2`
values.  This can be used with Julia's broadcasting to compute an Array of
spectral kurtosis estimates from Arrays of precomputed `S1` and `S2` values:

```julia
s1 = ... # an Array of S1 values
s2 = ... # an Array of S2 values
ske = SKEstimator(1024, 1, 1)
sk = skhat.(s1, s2, ske)
```

`sk` will have the same shape as the `S1` and `S2` Arrays.

### From an Array of data

Given an array `A` and an `SKEstimator`:

```julia
ske = SKEstimator(1024, 1, 1)
result = skhat(A, ske)
```

`result` is a named tuple `(; s1, sk)` where `s1` is the summed power and `sk`
is the spectral kurtosis.  See the [SKEstimator](@ref) page for details.

## Choosing thresholds

Outlier detection is typically done by comparing spectral kurtosis values
against lower and upper thresholds.  The [`pearson_distribution`](@ref)
function selects the most suitable Pearson distribution for an `SKEstimator`,
and [`thresholds`](@ref SpectralKurtosisEstimators.thresholds) computes the
lower/upper values corresponding to a given sigma level:

```julia
d = pearson_distribution(ske)
lo, hi = thresholds(d, 5)   # 5-sigma thresholds

sk = ... # An Array of spectral kurtosis estimates
outlier_indices = findall(x->!(lo <= x <= hi), sk)
```

See [Pearson Distributions](@ref) for the full list of supported distributions
and methods.
