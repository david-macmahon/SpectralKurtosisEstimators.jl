SpectralKurtosisEstimators.jl

Spectral Kurtosis estimators for Julia

SpectralKurtosisEstimators.jl provides the SKEstimator type and methods for working with them. It is based on the series of spectral kurtosis papers by G. M. Nita and D. E. Gary circa 2007-2016.

  • Radio Frequency Interference Excision Using Spectral‐Domain Statistics Nita [2007]
  • Statistics of the Spectral Kurtosis Estimator Nita [2010a]
  • A Wideband Spectrometer with RFI Detection Gary [2010]
  • The generalized spectral kurtosis estimator Nita [2010b]
  • EOVSA Implementation of a Spectral Kurtosis Correlator for Transient Detection and Classification Nita [2016]

Features

  • SKEstimator type encapsulating the first four moments of a generalized spectral kurtosis estimator
  • Pearson Type III, Type IV, and Type VI distributions for outlier detection
  • skhat functions for computing spectral kurtosis estimates from data
  • Threshold computation at arbitrary sigma levels

Installation

SpectralKurtosisEstimators.jl is not yet registered in the General registry. You can install it directly from the GitHub repository:

using Pkg
Pkg.add(url = "https://github.com/david-macmahon/SpectralKurtosisEstimators.jl.git")
